Alfresco Transform Service

The alfresco-transform-service chart deploys the document transformation services for Alfresco Content Services, enabling file format conversions and thumbnail generation.

Installation

helm install transform-service mbl-charts/alfresco-transform-service -f values.yaml

Overview

The Transform Service provides:

  • Document format conversion (e.g., Office to PDF)
  • Image transformations and thumbnails
  • Metadata extraction
  • Content renditions

Components

ComponentDescription
Transform RouterRoutes transformation requests to appropriate transformers
Transform Core AIOAll-in-one transformer for common formats
PDF TransformerSpecialized PDF transformations
ImageMagick TransformerImage format conversions
LibreOffice TransformerOffice document conversions

Key Configuration

Transform Router

transformrouter:
  replicaCount: 2
  resources:
    requests:
      cpu: 100m
      memory: 256Mi

Message Broker

messageBroker:
  url: failover:(nio://activemq:61616)?timeout=3000
  username: admin
  password: admin

Shared File Store

The transform service uses a shared file store for temporary files:

filestore:
  replicaCount: 1
  persistence:
    enabled: true
    storageClass: gp3
    size: 20Gi

Example Configuration

Basic Setup

transformrouter:
  replicaCount: 1
 
messageBroker:
  url: failover:(nio://activemq:61616)?timeout=3000
  existingSecret:
    name: activemq-credentials
 
filestore:
  persistence:
    enabled: true
    size: 10Gi

Production Setup with Dedicated Transformers

transformrouter:
  replicaCount: 2
  resources:
    requests:
      cpu: 200m
      memory: 512Mi
 
pdfrenderer:
  replicaCount: 2
  
imagemagick:
  replicaCount: 2
 
libreoffice:
  replicaCount: 2
  resources:
    requests:
      memory: 1Gi
    limits:
      memory: 2Gi
 
tika:
  replicaCount: 1
 
filestore:
  persistence:
    enabled: true
    storageClass: gp3
    size: 50Gi

Integration with Repository

The repository automatically discovers and uses the transform service when configured:

# In alfresco-repository values (no specific config needed if using same namespace)
# Transform service is auto-discovered via ActiveMQ

Resource Considerations

Different transformers have different resource requirements:

TransformerMemory (min)Memory (recommended)Notes
Transform Router256Mi512MiLow resource usage
PDF Renderer512Mi1GiModerate
ImageMagick512Mi1GiDepends on image sizes
LibreOffice1Gi2GiHigh memory for Office docs
Tika512Mi1GiMetadata extraction

Troubleshooting

Transformations Failing

  1. Check transformer pod logs:
kubectl logs -l app.kubernetes.io/component=transform-router
  1. Verify ActiveMQ connectivity
  2. Check file store availability

Slow Transformations

  1. Increase transformer replicas
  2. Add resource limits
  3. Consider dedicated transformers for heavy workloads
