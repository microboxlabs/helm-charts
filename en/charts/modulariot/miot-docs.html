miot-docs Chart

A Helm chart for deploying the ModularIoT documentation site - built with Next.js and Nextra.

Overview

The miot-docs chart deploys:

  • Next.js static documentation site
  • Nextra-powered documentation framework
  • Full-text search with Pagefind
  • Multi-language support

Prerequisites

  • Kubernetes 1.19+
  • Helm 3.0+

Installation

Standalone

helm install miot-docs microboxlabs/miot-docs \
  --namespace modulariot \
  --create-namespace

As part of umbrella chart

helm install modulariot microboxlabs/modulariot \
  --namespace modulariot \
  --set miot-docs.enabled=true

Example Configurations

Development

replicaCount: 1
 
image:
  tag: "latest"
 
service:
  type: NodePort

Production

replicaCount: 2
 
image:
  tag: "v1.0.0"
 
resources:
  limits:
    cpu: 500m
    memory: 512Mi
  requests:
    cpu: 100m
    memory: 256Mi
 
ingress:
  enabled: true
  className: nginx
  annotations:
    cert-manager.io/cluster-issuer: letsencrypt-prod
  hosts:
    - host: docs.modulariot.com
      paths:
        - path: /
          pathType: Prefix
  tls:
    - secretName: docs-tls
      hosts:
        - docs.modulariot.com

With Caching

ingress:
  enabled: true
  className: nginx
  annotations:
    nginx.ingress.kubernetes.io/proxy-buffering: "on"
    nginx.ingress.kubernetes.io/configuration-snippet: |
      proxy_cache_valid 200 1h;
      location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
      }
