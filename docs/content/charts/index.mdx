## Alfresco Charts

The Alfresco charts are a maintained fork of the official [Alfresco Helm Charts](https://github.com/Alfresco/alfresco-helm-charts).

| Chart | Description |
|-------|-------------|
| [alfresco-repository](/charts/alfresco/repository) | Alfresco Content Repository |
| [alfresco-search-enterprise](/charts/alfresco/search-enterprise) | Elasticsearch-based search |
| [alfresco-transform-service](/charts/alfresco/transform-service) | Document transformation |
| [alfresco-share](/charts/alfresco/share) | Alfresco Share web UI |
| [alfresco-sync-service](/charts/alfresco/sync-service) | Desktop Sync service |
| [activemq](/charts/alfresco/activemq) | ActiveMQ message broker |

See the [Alfresco Charts](/charts/alfresco) section for detailed documentation on each chart.
