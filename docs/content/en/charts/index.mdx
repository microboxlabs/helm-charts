# Charts Overview

This section contains documentation for all charts available in the MBL Helm Charts repository.

## ModularIoT Platform

Deploy the complete ModularIoT platform or individual components.

| Chart | Description | Version |
|-------|-------------|---------|
| [modulariot](/en/charts/modulariot) | Umbrella chart - deploys all components together | 0.1.0 |
| [miot-app](/en/charts/modulariot/miot-app) | Main application with auth & IoT features | 0.1.0 |
| [miot-docs](/en/charts/modulariot/miot-docs) | Documentation site (Nextra) | 0.1.0 |
| [miot-web-site](/en/charts/modulariot/miot-web-site) | Marketing website | 0.1.0 |

## Custom Microservice Charts

| Chart | Description | Version |
|-------|-------------|---------|
| [miot-calendar](/en/charts/miot-calendar) | Calendar booking microservice for resource scheduling | 0.1.0 |
| [quarkus-sse](/en/charts/quarkus-sse) | Helm chart for Quarkus Server-Sent Events applications | 0.1.2 |

## Alfresco Charts

The Alfresco charts are a maintained fork of the official [Alfresco Helm Charts](https://github.com/Alfresco/alfresco-helm-charts).

| Chart | Description |
|-------|-------------|
| [alfresco-repository](/en/charts/alfresco/repository) | Alfresco Content Repository |
| [alfresco-search-enterprise](/en/charts/alfresco/search-enterprise) | Elasticsearch-based search |
| [alfresco-transform-service](/en/charts/alfresco/transform-service) | Document transformation |
| [alfresco-share](/en/charts/alfresco/share) | Alfresco Share web UI |
| [alfresco-sync-service](/en/charts/alfresco/sync-service) | Desktop Sync service |
| [activemq](/en/charts/alfresco/activemq) | ActiveMQ message broker |

See the [Alfresco Charts](/en/charts/alfresco) section for detailed documentation on each chart.
